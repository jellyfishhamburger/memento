# MEMENTO

照片进去，成卷的书或者一张九宫格出来。核心是排版引擎，不是模板库。

在线版：https://jellyfishhamburger.github.io/memento/

## 两种输出

**作品集**：几十张照片 → 自动排出多页小书（杂志跨页 / 美术生小书 / Ins 跨页 / 胶片接触表），
可以导出长图、每页 PNG、多页 PDF。**页数可以锁定成九页**（封面 + 八个跨页，方版 1080），
导出的九张就是发朋友圈的那九张。

**九宫格**：每格一张（从一堆里挑九张）、或每格多张（全部照片压进九格）。

## 改版

- **点页面里的照片**：换一张（没在用的直接替换；已在别的页的跟它互换位置，版不变），
  或者删掉这张。删掉的可以撤销。
- **点左侧照片条**：删掉一张照片，整本自动重排——删到 30 张左右，版面会明显变松。
- 换图只重画，不重排；删图会重排。裁切按显著性焦点，人物优先保住头部。

## 打开方式

- 双击 `index.html` 就能用：选照片 / 拖照片进来 → 自动排 → 导出。
  照片在本机读，不上传；导出也不经过网络。
- 想在没照片的时候看示例：双击 `start.cmd`（起一个本地服务，示例图才读得到）。

## 引擎在做什么（不是套模板）

1. **读图**：每张照片算比例、显著性焦点（4×4 梯度网格）、三个主色、视觉强度（对比 + 饱和 + 焦点）。
2. **裁切**：按显著性焦点裁，不是居中裁，所以人脸和主体不会被切掉。
3. **选图**：`arFit`（少裁）＋ 视觉强度（当主角）＋ 色相接近（整页和谐）＋ 微小随机。
   九宫格用「最大差异」贪心：每挑一张都尽量与已选的九张不像。
4. **排位**：3×3 用局部搜索把相邻格的色相拉开、明暗错开，最强的放正中间。
5. **配页**：作品集按风格的节奏决定每页 1–4 张；页数不能凑的时候合并，不硬塞。

## 代码结构

```
index.html        外壳
css/app.css       界面样式（纸色 / 墨色 / 一个砖红点缀）
js/analyze.js     图片分析 + 缩小工作副本（26MP 原图会撑爆标签页）
js/engine.js      作品集引擎：风格 / 配方 / 选图打分 / 封面 / 装饰
js/grid.js        九宫格引擎：选九张 / 排位 / 1080 方块
js/render.js      同一份页面模型 → DOM 预览（所见即所得）→ Canvas 导出
js/export.js      PNG / 长图 / 手写的最小 PDF（JPEG XObject，无依赖）
js/app.js         状态、导入、重建、导出、灯箱
```

页面模型是唯一真相：`{w,h,bg,frames[],rects[],texts[]}`，坐标是页面像素。
DOM 和 Canvas 都从它画，所以缩略图、PDF、九宫格方块一定长得一样。

## 已知道具限制

- **HEIC**（iPhone 原生格式）浏览器解不了，导入会提示转 JPG。
- 九宫格目前是「自动选 + 换一组」，还不能逐格替换（下一步）。
- 作品集有预设配方内的调整，没有自由拖拽编辑器。
- 图注只有作品标题 + 年份，还没有逐页文字。

## 本地校验（需要 Node 22 + Chrome）

```
node _inspect/cdp.mjs <url> <expr.js>     # 开页面、跑断言、读结果
```
